# Chrome Web Store listing

Texts to paste into the [Developer Dashboard](https://chrome.google.com/webstore/devconsole), tab by tab. The extension UI is in English, so the main listing language is English; a French translation is provided for an optional second listing language.

## Package

- File: `dist/xid-converter-<version>.zip` (`npm run package`).
- The listing name, summary and icon come from `manifest.json`: **X-ID Converter**, the `description` field (90/132 characters) and `icons/icon-128.png`.

## Store listing

**Language**: English (en). Optional extra language: Français (fr).

**Category**: Developer Tools (Outils de développement).

**Description (en)**

```
Instantly convert an integer ID to its X-ID form (x + base 36) and back: 601814882 ⇄ x9yazc2.

• Right-click a selected ID on any page: the result is converted, copied to the clipboard and shown in a tooltip next to the selection.
• Popup: paste an X-ID or an integer, the conversion is instant; press Enter or the button to copy the result.
• Also works inside input fields.
• Exact BigInt arithmetic, even for very large IDs.
• Accepts surrounding whitespace and uppercase; rejects URLs, signs and multiple selections.

Privacy: everything runs locally. No network request, no telemetry, no permanent page access. The extension never reads the clipboard.

Source code (Apache 2.0): https://github.com/caketuzz/xid-converter
```

## Privacy

**Single purpose**

```
Convert an ID between its decimal integer form and its X-ID form (x followed by the base-36 representation), from the popup or the context menu, and copy the result.
```

**Permission justifications**

| Permission | Justification |
| --- | --- |
| `contextMenus` | Adds the "Convert X-ID ↔ integer and copy" entry to the context menu when text is selected. This is the extension's main entry point. |
| `clipboardWrite` | Writes the conversion result to the clipboard, at the user's request. The extension never reads the clipboard. |
| `offscreen` | An MV3 service worker cannot access the clipboard: an offscreen document (CLIPBOARD reason) performs the copy requested from the context menu. |
| `storage` | Keeps the last conversion and the last error message in `chrome.storage.session` (memory only) to show them in the popup. |
| `activeTab` | Temporary access to the tab where the user just used the context menu, to show the result tooltip there. No permanent page access. |
| `scripting` | Injects, into the tab granted by `activeTab`, the function that shows the tooltip next to the selection. No page content is read or sent. |

**Remote code**: No, I am not using remote code. All JavaScript is included in the package.

**Data usage**: check none of the data types (the extension collects no user data), then certify the three statements:
- I do not sell or transfer user data to third parties, outside of the approved use cases.
- I do not use or transfer user data for purposes that are unrelated to my item's single purpose.
- I do not use or transfer user data to determine creditworthiness or for lending purposes.
