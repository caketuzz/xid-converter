# Chrome Web Store listing

Texts to paste into the [Developer Dashboard](https://chrome.google.com/webstore/devconsole), tab by tab. The extension UI is in French, so the main listing language is French; an English translation is provided for an optional second listing language.

## Package

- File: `dist/xid-converter-<version>.zip` (`npm run package`).
- The listing name, summary and icon come from `manifest.json`: **X-ID Converter**, the `description` field (90/132 characters) and `icons/icon-128.png`.

## Store listing

**Language**: Français (fr). Optional extra language: English (en).

**Category**: Developer Tools (Outils de développement).

**Description (fr)**

```
Convertis instantanément un identifiant entier en X-ID (x + base 36) et inversement : 601814882 ⇄ x9yazc2.

• Clic droit sur un identifiant sélectionné dans n'importe quelle page : le résultat est converti, copié dans le presse-papiers et affiché dans une info-bulle à côté de la sélection.
• Popup : colle un X-ID ou un entier, la conversion est immédiate ; Entrée ou le bouton copie le résultat.
• Fonctionne aussi dans les champs de saisie.
• Calculs exacts en BigInt, même pour de très grands identifiants.
• Accepte les espaces autour de l'identifiant et les majuscules ; rejette les URL, signes et sélections multiples.

Confidentialité : tout fonctionne localement. Aucune requête réseau, aucune télémétrie, aucun accès permanent aux pages. L'extension ne lit jamais le presse-papiers.

Code source (Apache 2.0) : https://github.com/caketuzz/xid-converter
```

**Description (en)**

```
Instantly convert an integer ID to its X-ID form (x + base 36) and back: 601814882 ⇄ x9yazc2.

• Right-click a selected ID on any page: the result is converted, copied to the clipboard and shown in a tooltip next to the selection.
• Popup: paste an X-ID or an integer, the conversion is instant; press Enter or the button to copy the result.
• Also works inside input fields.
• Exact BigInt arithmetic, even for very large IDs.
• Accepts surrounding whitespace and uppercase; rejects URLs, signs and multiple selections.

Privacy: everything runs locally. No network request, no telemetry, no permanent page access. The extension never reads the clipboard.

The interface is in French.

Source code (Apache 2.0): https://github.com/caketuzz/xid-converter
```

## Privacy

**Single purpose**

```
Convertir un identifiant entre sa forme entière décimale et sa forme X-ID (x suivi de la représentation base 36), depuis la popup ou le menu contextuel, et copier le résultat.
```

**Permission justifications**

| Permission | Justification |
| --- | --- |
| `contextMenus` | Ajoute l'entrée « Convertir X-ID ↔ entier et copier » au menu contextuel lorsque du texte est sélectionné. C'est le point d'entrée principal de l'extension. |
| `clipboardWrite` | Écrit le résultat de la conversion dans le presse-papiers, à la demande de l'utilisateur. L'extension ne lit jamais le presse-papiers. |
| `offscreen` | Un service worker MV3 ne peut pas accéder au presse-papiers : un document hors écran (raison CLIPBOARD) effectue la copie demandée par clic droit. |
| `storage` | Conserve la dernière conversion et le dernier message d'erreur dans `chrome.storage.session` (mémoire uniquement) pour les afficher dans la popup. |
| `activeTab` | Accès temporaire à l'onglet où l'utilisateur vient d'utiliser le menu contextuel, pour y afficher l'info-bulle du résultat. Aucun accès permanent aux pages. |
| `scripting` | Injecte, dans l'onglet accordé par `activeTab`, la fonction qui affiche l'info-bulle près de la sélection. Aucun contenu de page n'est lu ni transmis. |

**Remote code**: No, I am not using remote code. All JavaScript is included in the package.

**Data usage**: check none of the data types (the extension collects no user data), then certify the three statements:
- I do not sell or transfer user data to third parties, outside of the approved use cases.
