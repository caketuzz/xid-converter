# Privacy policy — X-ID Converter

_Last updated: 2026-10-02_

🇫🇷 [Version française plus bas](#politique-de-confidentialité)

X-ID Converter does not collect, transmit, sell or share any personal or usage data.

- **No network**: the extension makes no network request. There is no server, analytics or telemetry.
- **Selected text**: when you use the context-menu entry, the selected text is converted locally in your browser. It is never sent anywhere.
- **Clipboard**: the extension only *writes* the conversion result to the clipboard, on your request. It never reads the clipboard.
- **Storage**: the last right-click conversion and the last error message are kept in `chrome.storage.session`, in memory only. They are erased when Chrome is closed.
- **Page access**: the extension has no permanent access to web pages. Right after you use the context menu, it uses the `activeTab` permission to display a tooltip with the result in that tab only. It does not read page content.

## Politique de confidentialité

_Dernière mise à jour : 2026-10-02_

X-ID Converter ne collecte, ne transmet, ne vend ni ne partage aucune donnée personnelle ou d'utilisation.

- **Aucun réseau** : l'extension n'effectue aucune requête réseau. Il n'y a ni serveur, ni statistiques, ni télémétrie.
- **Texte sélectionné** : lors du clic droit, le texte sélectionné est converti localement dans le navigateur. Il n'est jamais envoyé.
- **Presse-papiers** : l'extension *écrit* uniquement le résultat de la conversion dans le presse-papiers, à ta demande. Elle ne le lit jamais.
- **Stockage** : la dernière conversion par clic droit et le dernier message d'erreur sont conservés dans `chrome.storage.session`, en mémoire uniquement. Ils sont effacés à la fermeture de Chrome.
- **Accès aux pages** : l'extension n'a aucun accès permanent aux pages web. Juste après l'utilisation du menu contextuel, elle utilise la permission `activeTab` pour afficher une info-bulle avec le résultat dans cet onglet uniquement. Elle ne lit pas le contenu des pages.
